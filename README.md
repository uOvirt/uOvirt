Product Name: uOvirt 

Description:
Interactive uOttawa Campus Map is a web application that helps students find their way around campus. Along with buildings and classrooms, it shows where to find food courts, printers, and information desks, as well as good places to study, including study rooms you can reserve.

Folder structure
----------------

- `index.html`: opens the home page (GitHub Pages starts here)
- `shared.css`: styles used by every page (header, links, buttons, footer)
- Each page folder has its own `.html`, `style.css` and `script.js`, plus an `images` folder when it needs pictures
- `mockups/`: the design mockups we made before coding
- `style_guidelines.txt`: our colours, fonts, icons and buttons
